## 1. System Architecture: The Dual-Vector Energy Balance

The NorthPaw Index (NPI) operates as a unified scalar $0.0 - 10.0$ generated by taking the supremum of the two independent biophysical stress vectors:

$$\text{NPI}_{\text{unified}} = \max\left(\text{NPI}_{\text{heat}}, \; \text{NPI}_{\text{cold}}\right)$$

```
                                 ENVIRONMENTAL VECTOR
             (T_air, WindSpeed, SolarRadiation, Humidity, Precip, SnowCover)
                                          │
                  ┌───────────────────────┴───────────────────────┐
                  ▼                                               ▼
       HEAT STRESS ENGINE (CHSI)                       COLD STRESS ENGINE (CCSI)
     • Pavement surface thermal flux                 • Ground-level wind chill (WCT)
     • Solar coat irradiance                         • Tufts TACC hypothermia curve
     • Humidity wet-bulb impairment                  • Surface freezing & black ice
     • Snout penalty: Flat (+25%)                    • Chemical salt burn hazard
     • Coat penalty: Double (+15%)                   • Coat benefit: Double (-35%)
     • Mass penalty: Giant (+10%)                    • Mass penalty: Small/Toy (+35%)
                  │                                               │
                  ▼                                               ▼
              NPI_heat                                        NPI_cold
                  │                                               │
                  └───────────────────────┬───────────────────────┘
                                          ▼
                             SUPREMUM ARBITRATION ENGINE
                         NPI = max(NPI_heat, NPI_cold)
                                          │
                                          ▼
                               CANONICAL RISK VERDICT
                         🟢 Ready  |  🟡 Caution  |  🔴 Hazard
```

### Seasonal Dominance Regions
* **Temperate Window ($55^\circ\text{F} - 74^\circ\text{F}$):**
  * $\text{NPI}_{\text{heat}} \approx 0.0 - 1.5$
  * $\text{NPI}_{\text{cold}} \approx 0.0$
  * $\text{NPI}_{\text{unified}} \le 1.5 \implies$ **GREEN (Ready to go)**
* **Summer Window ($\ge 75^\circ\text{F}$):**
  * $\text{NPI}_{\text{heat}} \in [2.0, 10.0]$
  * $\text{NPI}_{\text{cold}} = 0.0$
  * $\text{NPI}_{\text{unified}} = \text{NPI}_{\text{heat}}$ (Asphalt paw burns, panting limits, shade-seeking).
* **Winter Window ($\le 45^\circ\text{F}$):**
  * $\text{NPI}_{\text{heat}} = 0.0$
  * $\text{NPI}_{\text{cold}} \in [1.0, 10.0]$
  * $\text{NPI}_{\text{unified}} = \text{NPI}_{\text{cold}}$ (Wind chill, frostbite, chemical salt, bootie alerts).

## 3. Advisor Copy State Machine

The hero advisor message dynamically reflects the active hazard driver:

```typescript
export function deriveActiveAdvisor(params: {
  npi: number;
  heatScore: number;
  coldScore: number;
  roadTempF: number;
  windChillF: number;
  isDeicerActive: boolean;
  snoutType: string;
  coatType: string;
}): { advisor: string; subtext: string; category: 'heat' | 'cold' | 'safe' } {
  // 1. Safe conditions
  if (params.npi < 3.5) {
    return {
      advisor: "Good to go right now.",
      subtext: "Conditions are comfortable for outdoor activity.",
      category: 'safe'
    };
  }

  // 2. Heat Dominant
  if (params.heatScore >= params.coldScore) {
    if (params.roadTempF >= 125) {
      return {
        advisor: "Dangerous pavement heat.",
        subtext: "Second-degree burns occur in <60 seconds. Stick to grass or shade.",
        category: 'heat'
      };
    }
    if (params.roadTempF >= 105) {
      return {
        advisor: "Hot road surfaces.",
        subtext: "Paw pads at risk of blistering. Check temperature with hand test.",
        category: 'heat'
      };
    }
    if (params.snoutType === 'flat') {
      return {
        advisor: "Elevated respiratory heat stress.",
        subtext: "Flat-faced breeds struggle to pant. Keep walk short and hydrated.",
        category: 'heat'
      };
    }
    return {
      advisor: "Warm outdoor conditions.",
      subtext: "Monitor your dog closely for heavy panting.",
      category: 'heat'
    };
  }

  // 3. Cold Dominant
  if (params.isDeicerActive) {
    return {
      advisor: "Chemical road salt hazard.",
      subtext: "Caustic de-icers irritate and burn pads. Use booties or wipe paws post-walk.",
      category: 'cold'
    };
  }
  if (params.windChillF <= 15) {
    return {
      advisor: "Severe wind chill & frostbite risk.",
      subtext: "Keep outings strictly under 10–15 minutes for potty relief.",
      category: 'cold'
    };
  }
  if (params.coatType === 'Short' || params.coatType === 'hair') {
    return {
      advisor: "Chilly conditions for thin coat.",
      subtext: "Rapid convective body heat loss. Consider an insulated dog jacket.",
      category: 'cold'
    };
  }
  return {
    advisor: "Freezing outdoor temperatures.",
    subtext: "Check paws periodically for ice balls between toes.",
    category: 'cold'
  };
}
```
