# 13 — Ideas

> Every potential future feature, experiment, and crazy thought.
>
> Nothing here is committed.
>
> An idea enters this document before it enters the roadmap.
>
> Before promotion it must answer:
>
> 1. Does it help dog owners make better outdoor decisions?
> 2. Does it help grow the user base?
>
> If neither answer is yes, it stays here forever.
