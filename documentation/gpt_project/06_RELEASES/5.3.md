# 5.3 — Polish, Accessibility, Stability

**Shipped:** August 1, 2026 (submitted to App Store Connect)
**App Store version:** 5.3.0 (build 1)

> A quality release. No new headline features — the goal was to make NorthPaw feel like a finished product.

---

## Highlights

- **Accessibility sweep** — contrast pass across the app; WCAG AAA text colors in light and dark; solid backgrounds on utility screens replacing text-over-photography (driven by Gabriel's feedback)
- **App Review prompt flow** — gentle, guarded cross-platform review prompts: eligibility rules, session guards, quick-star and written paths, "later" snooze, "never" respected, store fallback, developer test trigger
- **Onboarding streamlining** — photo step moved post-activation with explicit skip and default avatar badge; breed search input focus, search key, and nested scroll fixes
- **Share cards restored** — ShareCard image generator fixed and placed under the timeline
- **Weather timeline integrity** — backfill from midnight for full-day view; timeline hours aligned with forecast samples (pill and surface boxes match 100%); real-time current hourly air temp (no more daily-max fallback); explicit air-temp estimation on the details modal
- **Legal/versioning hardening** — disclaimer acceptance decoupled from app version (`REQUIRED_DISCLAIMER_VERSION`); dynamic version checks; clean Privacy/Support/Terms links to northpawapp.com

## Fixes (the 5.3 QA class)

- **Timer stuck-screen bug** — timer reset + AppState background safeguards; fixed scan tab trap
- **Current temp fallback** — real-time current hourly air temp extraction
- **Timeline overwrite/alignment** — hours matched to forecast samples + 5-case regression suite (hourly temp fallback, boundary hour selection, timeline pill/box alignment)
- **Checklist toggle** — checklist toggling fixed
- Review flow state persistence ordering + session-level guard
- Android DateTimePicker loop resolved; 1st/15th monthly care presets; iOS monthly care preset highlighting and exact month boundaries
- Layout padding fixes
- Onboarding photo analytics events (uploaded/skipped)

## Community

- Breeds added: Maltipoo, Old English Sheepdog, Aussiedoodle, Great Pyrenees, American Eskimo, Standard Schnauzer
- Background Google Sheets watcher for breed requests with 12-hour alert throttling, generic user copy, sanitized payload, friendly 429 rate-limit message

## Telemetry

- `weather_provider_used` (nws | tomorrow | cache) added to weather events
- Non-production Mixpanel safeguards (dev/TestFlight muted by default)
- Review prompt funnel events (eligible → shown → quick star / written / later / never / store fallback)
